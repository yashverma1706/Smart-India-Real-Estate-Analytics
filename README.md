# Smart India Real Estate Analytics

A production-oriented machine learning project skeleton for real estate analytics and house price prediction.

## Structure

- `data/raw/`: place original datasets such as `Real Estate Data V21.csv` here.
- `data/processed/`: store cleaned and transformed datasets.
- `notebooks/`: analysis and modeling notebooks organized by ML lifecycle.
- `src/`: reusable production code and model backend components.
- `models/`: trained model artifacts.
- `app/`: Streamlit or frontend integration assets.
- `tests/`: unit and integration tests.

## Setup

1. Create a virtual environment.
2. Install dependencies from `requirements.txt`.
3. Keep raw dataset files unchanged in `data/raw/`.
